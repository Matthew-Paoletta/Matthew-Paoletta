# ⭐ Featured Project

## 📅 WebReg2Cal

A Chrome Extension that automatically imports university class schedules into Google Calendar.

### Impact

- 🚀 Published on the Chrome Web Store
- 📥 **340+ installs**
- 👀 **630+ Chrome Web Store page views**
- 📈 **37 users on the busiest day**
- ⏱️ Eliminates manual schedule entry for students

**Technologies**

JavaScript • Chrome Extension API • Google Calendar API • REST APIs
